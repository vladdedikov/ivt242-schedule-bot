# Расписание ИВТ-242 в Telegram

Личный бот: расписание на сегодня, завтра и выбранную дату, ежедневное сообщение по будням в **07:30 по Москве**.

Кнопка **«Выбрать день»** открывает даты недели. Стрелки переключают недели. Команды: `/today`, `/tomorrow`, `/days`.

## Запуск на Windows

1. Установи Python 3.9 или новее с [python.org](https://www.python.org/downloads/). Включи **Add Python to PATH** в установщике.
2. Скачай проект через **Code → Download ZIP** и распакуй архив.
3. Если этот же бот уже работает на Mac, сначала останови его там. Две копии одного бота не должны работать одновременно.
4. Открой `start.bat`: он установит пакет часовых поясов `tzdata` и запустит бота.
5. Вставь токен BotFather в окно программы. Ввод скрыт — это нормально.
6. Отправь своему боту команду `/start` с кодом, показанным программой. Бот пришлёт расписание для проверки.

ПК должен оставаться включённым, иметь интернет и не переходить в сон. Экран можно выключать. Окно программы нужно оставлять открытым.

Для автозапуска после входа в Windows: нажми **Win+R**, введи `shell:startup` и положи в открывшуюся папку **ярлык на start.bat**. После перезагрузки необходимо войти в Windows. В параметрах электропитания установи переход в сон «Никогда» при питании от сети.

## macOS и Linux

```sh
python3 -m pip install -r requirements.txt
python3 bot.py
```

На Mac также можно открыть `Запустить.command`. При первом запуске программа запросит токен и привяжет чат через одноразовый код. Для повторной привязки: `python3 bot.py --setup`.

В текущей установке Mac настроен фоновый агент `local.ivt242.schedulebot`. Перед переносом останови его:

```sh
launchctl bootout gui/$(id -u)/local.ivt242.schedulebot
```

Чтобы агент не вернулся после следующего входа в macOS, перемести `~/Library/LaunchAgents/local.ivt242.schedulebot.plist` из папки LaunchAgents. Рабочая копия бота на Mac находится в `~/Library/Application Support/IVT242Bot`.

## Личные настройки

`config.json` с токеном и идентификатором чата создаётся при настройке. `state.json` хранит последнюю отправленную дату и позицию обработки Telegram. Эти файлы и журналы исключены из Git. На новом ПК токен нужно ввести локально.

Если бот был выключен в 07:30, после запуска он отправит расписание за текущий будний день. Повторная отправка за день подавляется сохранённым состоянием; при сбое непосредственно после отправки возможен повтор.

## Источник расписания

Данные извлечены из третьего листа предоставленного XLSX — «3 курс ИВТ ПИ», группа ИВТ-б-о-242. Год **2026** выбран по учебному периоду: в шапке исходного файла год отсутствует. Чётность определяется датами понедельников из файла. Для недель вне исходника бот сообщает, что нужен новый файл. Праздники и переносы автоматически не учитываются.

Время пар взято из предоставленного изображения, пары 1–7. В 8-й паре у группы занятий нет. Примечание «Схемотехника 4» в нечётный понедельник сохранено без интерпретации. В нечётный вторник для 5-й пары вид занятия отсутствует: ПЗ принят по совпадающей чётной неделе.

Обновление из файла с той же структурой:

```sh
python3 extract_schedule.py /путь/к/расписанию.xlsx
```

При фоновом запуске обновляй файлы именно в рабочей папке бота и перезапускай процесс.

## Проверки

```sh
python3 -m unittest -v
python3 bot.py --preview 2026-10-30
```

Используется [Telegram Bot API](https://core.telegram.org/bots/api). На macOS/Linux внешние Python-библиотеки для работы бота не требуются.
